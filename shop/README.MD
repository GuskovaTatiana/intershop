# Веб-приложение Интернет Магазин

Этот проект представляет собой простое веб-приложение для покупки детских товаров, позволяющее пользователям создавать заказы.

## Особенности

**Просмотр Списка Товаров:** Все Пользователи могут посмотреть список товаров, фильтровать по названию или описанию товара, сортировать по названию или цене товаров

**Просмотр Товара:** Все Пользователи могут посмотреть полную информацию о товаре, Но только авторизованные пользователи могу добавить этот товар в корзину, увеличить его количество в своей корзине, или удалить его из корзины.

**Просмотр Корзины:** Авторизованные Пользователи могут посмотреть список товаров в корзине, увеличивать количество товара, удалить товар из корзины, посмотреть итоговую стоимость заказа.

**Просмотр Списка Заказов:** Авторизованные Пользователи могут посмотреть список всех оформленных заказов, сокращенную информацию по ним.

**Просмотр Заказа:** Авторизованные Пользователи могут посмотреть список товаров в заказе, с полной информацией по купленным товарам.

## Технологии

**Фронтенд:** HTML, CSS, JavaScript

**База данных:** PostgreSQL, Redis

**Контейнер:** Docker

**Aвторизационный сервер:** Keycloak

## Предварительные требования
**Установить сторонние технологии:**
1. postgreSQL
2. JAVA 21
3. Redis
4. Keycloak
5. Docker

## Настройка перед запуском
**Настройте базу данных:**
1. Создайте базу данных.
2. Обновите файл конфигурации application.yml с учетными данными базы данных.

**Настройте порт:**
1. Обновите файл конфигурации application.yml. укажите свободный порт в поле server.port.

**Настройте Keycloak:**
1. В терминале запустите процесс генерации контейнера в Docker
   ```
   docker run -d \
      --name keycloak \
      -p 8007:8080 \
      -e KC_BOOTSTRAP_ADMIN_USERNAME=admin \
      -e KC_BOOTSTRAP_ADMIN_PASSWORD=admin \
      quay.io/keycloak/keycloak:latest \
      start-dev
``
2. Наберите в браузере http://localhost:8007/
3. Авторизуйтесь с указаными выше логином и паролем
4. На вкладке manage Realms нажмите кнопку Create realm
5. В поле Realm name введите "ecommerce-realm" (без кавычек) и нажмите кнопку Create
6. Перейдите во вкладку Clients и нажмите кнопку Create client
7. Внесите в поле client ID значение shop-client (взято из файл конфигурации application.yml)
8. На 2 вкладке включите настройки:
8.1. Client authentication
8.2. Direct access grants
8.3. Standard flow
8.4. Service accounts roles
9. На 3 вкалдке ничего не меняем и сохраняем клиента
10. На странице клиента переходим во вкладку Credentials и копируем Client secret
11. Вставляем скопированный ключ в файл конфигурации application.yml по пути spring.security.oauth2.client.registration.keycloak.client-secret
12. Повторяем шаги 6-10 для клиента с id **shop-to-payment**
13. Вставляем скопированный ключ в файл конфигурации application.yml по пути payment-service.oauth2.client-secret


**Создайте образ проекта:**
1. В терминале запустите сборку проекта ./gradlew :shop:bootJar

## Запуск
1. **Через терминал запустите файл shop-0.3.jar**
2. **В выбранном браузере наберите строку: http://localhost:8006/product**
