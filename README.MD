## Запуск приложений в Docker:
### Установка
1. Перед запуском приложения убедитесь, что у вас установлен **Docker-контейнер**

### Настройка порта
1. В файле docker-compose.yml укажите свободный порт в поле app-shop:ports:- "[свободный порт]:8006".
2. 1. В файле docker-compose.yml укажите свободный порт в поле app:app-payment-service:- "[свободный порт]:8009".

### Запуск
1. В терминале наберите команду  docker-compose up -d --build
2. Дождитесь польной сборки
2. В выбранном браузере наберите строку: http://localhost:8006/product
